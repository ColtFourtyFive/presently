# Deferred material

Nothing in this folder is part of the shipped product. It is kept, not deleted, so earlier work stays available for reference or later reuse.

| Folder | What it holds | Why it is deferred |
| --- | --- | --- |
| `railway-edition/` | The original Express + PostgreSQL edition: server, client, tests, Railway config | The product ships as one Cloudflare installation per franchise business. This edition is no longer maintained. |
| `kumon-branding/` | Kumon logo and icon files | The product uses its own name. Kumon marks must not be shipped without written permission from Kumon. |
| `requirements-research/` | Requirements drafts (BRD/FRD/FDR), the franchisor requirements text, vendor research and scraped vendor pages, generated documents | Internal research. Third-party and franchisor material must not be redistributed with the product. |
| `planning-docs/` | Earlier delivery plans, status trackers and proposals | Superseded by the current business model and root README. |
| `cloudflare-feasibility/` | Checkpoint notes, design reviews, the archive/retention subsystem, Google Drive backup, inquiries, schedules, the communication log, and the original migrations and tests | Out of v1 scope, or replaced by a simpler design. |

This repository is public today. Moving files here does not stop them from being published. The third-party and franchisor material in `requirements-research/` should be removed from public history, or the repository made private, before outreach begins.
